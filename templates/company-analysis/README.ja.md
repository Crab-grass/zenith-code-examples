# 企業・決算分析テンプレート

[English](README.md) · [リポジトリのREADME](../../README.ja.md)

会社の業績を表とグラフで確認できる、ZENITH Codeの公式サンプル画面です。自分の分析ツールを作る出発点として、コードを変更して使えます。

![企業・決算分析テンプレート。企業名・数値はすべて架空のデモです。](../../assets/company-analysis-ja.png)

## 1. 登録不要で試す

必要なものは**Python 3.9以上とブラウザ**です。追加パッケージやビルド作業はありません。

```sh
git clone https://github.com/Crab-grass/zenith-code-examples.git
cd zenith-code-examples
python3 templates/company-analysis/server.py
```

端末に表示された **http://127.0.0.1:8765** をブラウザで開きます。終了するときは端末で **Ctrl+C** を押します。ポートが使用中なら`--port 8766`のように変更できます。

- 「架空精密工業」「架空クラウド」を選び、「表示する」で切り替え。
- グラフのメニューから売上高・営業利益・純利益を選択。
- JA / ENで画面・グラフ・注記を切り替え。
- 財務の表で円単位の数値・利益率・決算期間の日数・会計基準を確認。
- 「出典情報を確認」で、元のprovenanceを確認。

**デモの企業名・株価・財務数値はすべて架空です。** API通信も登録も不要です。「架空クラウド」には、赤字や未開示の例も含めています。

## 2. 実際のデータに接続する

[会員登録](https://zenithcode.net/sign-up)後、適用される規約・データ利用条件に同意し、ダッシュボードでAPIキーを作成します。いったんCtrl+Cで終了して、次で起動し直します。

```sh
python3 templates/company-analysis/server.py --live
```

端末の非表示入力でキーを設定します。環境変数`ZENITH_API_KEY`に設定済みの場合はそちらを利用します。`.env`は自動で読み込みません。

画面の「実データに接続」を選択し、証券コード（例：`7203` / `130A`）を入力して「データを取得」を押します。**キーはブラウザへ送らず、ローカルのPythonプロセスだけが保持します。** このテンプレートはデータやキーをファイル・ブラウザの保存領域に記録しません。

1回の取得で、既存の`snapshot`サンプルを呼び出します。

| API | 表示内容 | リクエスト / APIトークン |
| --- | --- | --- |
| `/stable/quote` | 直近終値・株価日付 | 1 / 1 |
| `/stable/income-statement?period=annual&limit=3` | 最新3通期までの損益計算書・出典 | 1 / 1 |

公開OpenAPI仕様を2026-10-26に確認。最新のプラン・利用枠・データ利用条件が適用されます。起動時・言語変更時・グラフ切り替え時には実APIを呼びません。自動更新・リトライ・追加購入は行いません。途中で取得に失敗した場合は、その操作の結果を表示しません。

## 数字を誤読しないために

- 財務は**FY（通期）だけ**を扱います。累計四半期の差分計算はこの画面では行いません。
- グラフと金額カードは億円、財務の表は円。英語では`JPY 100 million`と表記します。
- 営業利益率はAPIの値を百分率で表示します。0.125なら12.5%です。
- 欠損値は「—」として残し、棒を作らず、折れ線をつなぎません。実際の0は0のままです。
- 比較用に会計基準と期間日数も表示しますが、連結範囲変更・決算期変更等を調整した比較ではありません。独自の前年比・PER・PBRは計算しません。
- 株価の日付、決算期、取得日時、行の更新日時を区別します。取得日時は原本の公表日時ではありません。
- `provenance`は項目別出典・訂正情報も含め、そのまま表示します。書類URLへ自動でアクセスしません。
- 実データでは企業名を取得する追加APIは呼ばず、証券コードを見出しに表示します。

## 自分の用途に合わせて変更する

| ファイル | 役割 |
| --- | --- |
| `server.py` | 127.0.0.1だけで待ち受けるローカルサーバー。既存APIサンプルを利用 |
| `index.html` / `style.css` | 画面構成・色・レスポンシブレイアウト |
| `app.mjs` | 表・SVGグラフ・日本語と英語の表示 |
| `model.mjs` | 期間の並べ替え、入力検証、数値と単位の表示 |
| `demo.json` | 公開可能な架空のデモデータ |

ブラウザから任意のURLへ通信する機能はありません。サーバーはローカルHost・Origin・リクエストトークンを確認し、実データ取得の同時実行を抑えます。**これは個人のローカル利用向けテンプレートです。** インターネット公開用・複数ユーザー用の認証や権限管理は実装していません。
