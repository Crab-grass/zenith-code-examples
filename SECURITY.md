# Security reporting

Please report suspected vulnerabilities privately to [support@zenithcode.net](mailto:support@zenithcode.net). Include the affected example and reproduction steps using synthetic data. Never include a live API key in a public issue.

If a key has been exposed, revoke it in your ZENITH Code dashboard and create a replacement.

脆弱性は公開Issueではなく、support@zenithcode.netへご連絡ください。再現手順には架空のデータを使い、実際のAPIキーを含めないでください。キーが漏れた場合はダッシュボードで失効し、再発行してください。
