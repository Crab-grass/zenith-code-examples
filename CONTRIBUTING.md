# Contributing

Small, runnable examples and documentation fixes are welcome. Keep examples dependency-free where practical and update both READMEs when changing their usage.

- Use synthetic fixtures for tests. Do not attach live market data, TDnet documents/links, API keys, account information or private logs.
- Preserve dates, periods, units, null values and provenance. Never silently treat missing values as zero.
- Keep network requests bounded. Do not add automatic purchases, unbounded retries or browser-side API keys.
- Run the Python and JavaScript tests listed in the README before submitting a pull request.
- Code contributions are provided under this repository's MIT licence; API data remains subject to its own terms.

For API-account support, use [the support form](https://zenithcode.net/contact). For business questions, use [the sales form](https://zenithcode.net/contact-sales).

日本語でのIssue・Pull Requestも歓迎します。実データや秘密情報を添付せず、架空の値で再現手順を書いてください。
