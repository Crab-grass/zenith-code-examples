# Repository visuals

- `zenith-code-overview.webp`: service screenshot supplied by Crabgrass on 2026-10-26. Converted from PNG to WebP at the original 1440 × 810 resolution. Figures and interface reflect the capture date; the live service is authoritative. The service screenshot/branding is not a market dataset or an API response.
- `quarterly-sales.svg` (Japanese): authored synthetic teaching chart, generated with `python3 python/quarterly_chart.py --output assets/quarterly-sales.svg`. All amounts are fictional. No actual company filing or market data is included.

- `quarterly-sales.en.svg` (English): the same synthetic chart with English labels, generated with `python3 python/quarterly_chart.py --lang en --output assets/quarterly-sales.en.svg`.
