# Ask Claude about Japanese annual reports through MCP

Figures for the dev.to article on using the ZENITH Code MCP server (`get_workforce`, `get_subsidiaries`, `get_cross_shareholdings`, `get_diversity_metrics`) to compare Toyota, Honda and Nissan without writing code.

- `cover-v1.png` — article cover.
- `q1-workforce-v1.png` — recreated chat: consolidated vs. parent headcount, parent salary, age, tenure, and listed subsidiaries vs. "other" counts (FY2026-03).
- `q2-cross-shareholdings-v1.png` — recreated chat: number of listed strategic holdings and how many investees also hold the filer's shares (counts only, FY2026-03).
- `q3-diversity-v1.png` — recreated chat: female managers, women's pay as % of men's, and male childcare leave with its calculation basis (FY2026-03).

Screens are recreated for illustration; every number comes from the actual API responses (some are computed from them, e.g. totals and ratios; retrieved 2026-11-25 18:13:12–18:13:34 JST).
